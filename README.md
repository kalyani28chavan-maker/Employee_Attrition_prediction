# Employee Attrition Prediction

## AI Powered HR Analytics Dashboard

An end-to-end Machine Learning project that predicts employee attrition risk and helps HR teams understand employee turnover patterns.

## Project Overview

Employee attrition is a major challenge for organizations. This project uses Machine Learning to predict whether an employee may leave the company based on employee-related information.

## Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn
- Random Forest Classifier
- Streamlit
- Plotly
- GitHub

## Dataset

IBM HR Analytics Employee Attrition Dataset

- Total Employees: 1,470
- Total Features: 35
- Target Variable: Attrition

## Machine Learning Model

Random Forest Classifier

Model evaluation results:

- Accuracy: 82.99%
- Attrition Precision: 43%
- Attrition Recall: 48.94%
- ROC-AUC Score: 0.7597

## Dashboard Features

- Employee Attrition Prediction
- Employee Risk Percentage
- Department-wise Attrition Analysis
- Monthly Income Analysis
- Overtime Analysis
- Feature Importance Visualization
- Model Performance Metrics
- HR Business Insights

## Deployment

Built and deployed using Streamlit.

## Disclaimer

Predictions are estimates based on historical data and should not be treated as guaranteed outcomes or the sole basis for HR decisions.
